# KFC Clone Website

A fully responsive, professional KFC restaurant clone website built with HTML and Tailwind CSS (no JavaScript required).

## 🎯 Features

### Pages Included
1. **Homepage (index.html)**
   - Eye-catching hero section with CTAs
   - Browse categories section
   - Best sellers showcase
   - Exclusive offers banner
   - Why choose KFC section
   - Mobile app download section
   - Fully responsive footer

2. **Menu Page (menu.html)**
   - Complete menu with 6 categories:
     - Chicken Buckets (6 items)
     - Burgers (6 items)
     - Biryani Buckets (4 items)
     - Snacks & Sides (6 items)
     - Beverages (5 items)
     - Desserts (4 items)
   - Sticky category navigation
   - Product cards with images, prices, and badges
   - Smooth anchor link navigation

3. **Deals Page (deals.html)**
   - 6 super saver combos with discount badges
   - Value for money section
   - Special day offers (Tuesday special)
   - Student offers section
   - App-exclusive deals banner
   - Attractive gradient designs

4. **Locations Page (locations.html)**
   - Store locator with search functionality
   - Quick city links
   - Store listings for 3 major cities (Mumbai, Delhi, Bangalore)
   - Store cards with:
     - Operating hours
     - Contact numbers
     - Location details
     - Call-to-action buttons
   - Delivery partners section

5. **About Page (about.html)**
   - Company heritage and history
   - Colonel Sanders story
   - Core values (6 values)
   - Quality promise
   - India journey statistics
   - Career opportunities section

## 🚀 How to Use

1. **Open the Website**
   - Simply open `index.html` in any modern web browser
   - No build process or dependencies required

2. **Navigation**
   - Use the header navigation to switch between pages
   - All links are functional and interconnected
   - Smooth scrolling for in-page navigation on menu page

3. **Browse Menu**
   - Click on category badges to jump to specific sections
   - View items with prices, images, and descriptions
   - Responsive grid layout adjusts to screen size

4. **View Deals**
   - Explore combo offers with discount percentages
   - Check special day offers
   - Student offers with valid student ID

5. **Find Locations**
   - Use quick city links for major cities
   - View store details including hours and contact
   - Each store has directions and order buttons

## 📱 Responsive Breakpoints

- **Mobile**: < 768px (Stack layout, mobile menu)
- **Tablet**: 768px - 1024px (2 columns)
- **Desktop**: > 1024px (3-4 columns, full layout)
